# 블로그 전체 페이지 기획 및 아이디어 정리

이 문서는 본 블로그에 포함될 페이지와 목적 및 설계 정리
각 페이지는 별도의 설계 문서(.md) 및 figma 링크 연결

## 전체 페이지 구성

| 경로          | 페이지 이름         | 목적                                     | 우선순위            | 설계 문서                                    |
| ------------- | ------------------- | ---------------------------------------- | ------------------- | -------------------------------------------- | -------------------- |
| `/`           | homepage            | 블로그 소개 + 추천 링크                  | 1순위               | [pages.home.md]                              |                      |
| `/about`      | 자기소개            | 소개 및 포트폴리오                       | ⭐️ 1순위           | [pages.about.md](./docs/README.about.md)     |                      |
| `/gallery`    | 나만의 갤러리       | 이미지 전시 공간                         | ⭐️ 1순위           | [pages.gallery.md](./docs/README.gallery.md) |                      |

## 특별 기능 메모

- `/gallery` 내부 기능으로써:
  - 썸네일 클릭 시 **모달 팝업**으로 이미지 확대 보기
  - 향후 필요시 `/gallery/[id]` 형태로 개별 이미지 페이지 확장 고려
- `/posts`와 `/admin`은 현재는 불필요하지만, 글 작성/관리를 시작하게 되면 확장 예정
- 모든 페이지는 반응형 레이아웃을 고려하여 설계됨 (Figma에서 시각화 예정)
