# 📄 /about (All-in-One 포트폴리오 페이지) 설계 문서

## 1. 페이지 목적

- 블로그 주인인 "나"를 소개하는 공간
- 개발자로서의 가치관, 관심 분야, 기술 스택, 프로젝트 경험을 함께 보여주는 **1페이지 포트폴리오**
- 방문자에게 신뢰와 인상을 주는 메인 자기소개 페이지로 활용

---

## 2. 주요 구성 요소

### ✅ 프로필 영역

- 프로필 이미지 (원형)
- 이름 / 닉네임
- 짧은 한 줄 소개 (예: "꾸준히 성장하는 백엔드 개발자 지망생")

### ✅ 자기소개 텍스트

- 어떤 사람인지, 어떤 걸 공부하고 있는지
- 어떤 일을 하고 싶은지
- 블로그를 만든 이유

### ✅ 기술 스택

- 사용 중이거나 학습 중인 기술
- 아이콘 + 텍스트 혼합 형태 (예: JavaScript, React, Node.js, Figma 등)

### ✅ 프로젝트 섹션

- 대표 프로젝트 1~3개 카드 형식으로 소개
  - 프로젝트 제목, 기간, 설명, 기술 스택
  - GitHub or 배포 링크

### ✅ 경력 타임라인

- 학습 과정, 프로젝트 참여, 주요 이력 등을 타임라인 형식으로 시각화

### ✅ 이력서 다운로드 (후순위)

- PDF 첨부 or 외부 링크로 다운로드 버튼

### ✅ 외부 링크 버튼

- GitHub
- Email

---

## 3. 레이아웃 구조

### 💻 데스크탑

- 상단: 프로필 + 간단 소개
- 하단: 섹션별로 수직 정렬 (자기소개 → 기술 → 프로젝트 → 타임라인 → 링크)

### 📱 모바일

- 동일하게 수직 정렬
- 각 섹션 간 충분한 여백으로 구분

---

## 4. 기능 및 인터랙션

- 외부 링크 버튼은 `target="_blank"`로 새 탭 열림
- 버튼 hover 시 색상 변화 또는 아이콘 애니메이션
- 프로젝트 카드 클릭 시 새 탭으로 GitHub or 배포 링크 이동
- 타임라인 애니메이션 적용

---

## 5. 디자인 요소(수정예정)

| 항목        | 내용                        |
| ----------- | --------------------------- |
| 배경색      | 베이지 or 아이보리 톤       |
| 텍스트 색   | 짙은 회색 or 검정           |
| 폰트        | Pretendard or Noto Sans     |
| 카드 스타일 | 살짝 둥근 모서리 + 그림자   |
| 여백        | 섹션 간 32px, 요소 간 16px  |
| 버튼 스타일 | 테두리형 + 아이콘 포함      |
| 반응형      | Tailwind 기준 sm/md/lg 대응 |

---

## 6. 향후 확장 고려

- `/projects` 페이지로 프로젝트 분리
- `/career` 또는 `/timeline` 페이지로 경력 독립
- 이력서 페이지 or 파일 업로드 기능(후 순위)
- 다국어 지원 (한국어/영어 버전 나눔)
