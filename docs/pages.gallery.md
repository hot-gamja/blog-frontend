# 📷 `/gallery` 페이지 기획 문서 (인스타그램 스타일)

---

## 1. 📌 페이지 목적

- 나만의 이미지 아카이브 공간
- 작업물, 일상, 관심 있는 것들을 시각적으로 표현
- 인스타그램 피드처럼 직관적이고 감각적인 UI 구성
- 방문자에게 감각적 취향과 활동 영역을 보여주는 갤러리

---

## 2. 🔧 주요 기능

| 기능                   | 설명                                             | 포함 여부 |
| ---------------------- | ------------------------------------------------ | --------- |
| 📸 썸네일 그리드       | 정사각형 이미지들을 3~4열 그리드로 배치          | ✅        |
| 🔍 클릭 시 슬라이드 뷰 | 하나의 게시물에 여러 장의 이미지 슬라이드로 표시 | ✅        |
| 📝 사진 설명           | 상세 뷰에서 텍스트 설명 가능                     | ✅        |
| 🏷️ 태그                | 사진 분류용 태그 표시 (ex. #일상 #프로젝트)      | ✅        |
| 📆 업로드 날짜         | 사진 업로드 or 게시 날짜 표시                    | ✅        |
| 🔄 최신순 정렬         | 최신 → 오래된 순으로 정렬                        | ✅        |
| 📱 반응형 레이아웃     | 모바일, 태블릿, 데스크탑에 최적화                | ✅        |

---

## 3. 🧠 사용자 흐름 (User Flow)

[Gallery 메인 페이지]
└─ 썸네일 이미지들이 그리드로 나열됨 (3열)

[썸네일 클릭]
└─ 슬라이드 상세 뷰
├─ 이미지 여러 장 슬라이드
├─ 설명 / 태그 / 날짜
└─ 이전/다음 버튼으로 전환

---

## 4. 🖼️ 썸네일 이미지 규칙

- 기본 비율: `1:1` (정사각형)
- 모든 썸네일은 정사각형으로 강제 렌더링 (`aspect-ratio: 1 / 1`)
- 이미지 크기가 맞지 않을 경우, `object-fit: cover` 처리
- 썸네일에는 설명 없이 이미지 중심 UI

```css
.gallery-thumbnail {
  aspect-ratio: 1 / 1;
  object-fit: cover;
  width: 100%;
}

## 5. 💡향후 확장 고려
| 기능        | 설명                 | 순서 |
| --------- | ------------------ | --------- |
| ❤️ 좋아요 기능 | 방문자가 좋아요를 누를 수 있음  | 1순위 |
| 💬 댓글 기능  | 사진에 댓글 달 수 있는 공간   | 2순위 |
| 📁 앨범 분류  | 여러 갤러리를 주제별로 묶기    | 추후 고민 |
| 🔒 비공개 설정 | 비공개 이미지 분류 및 접근 제한 | 추후 고민 |
| ⏬ 무한 스크롤  | 페이지네이션 대신 스크롤로 로딩  | 3순위 |
```
